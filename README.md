# Healthcare Administration Freebies Kit

A free, fillable, printable, large-print-friendly kit of healthcare administration forms — built for busy healthcare workers who need straightforward paperwork tools. No account needed. Nothing is uploaded. Just open an HTML file in any browser, fill it in on screen or print it out and write by hand.

## What's inside

| File | What it's for |
|------|---------------|
| `forms-completeness-checklist.html` | Verify admission/encounter paperwork is complete before it leaves the unit |
| `deadline-calendar.html` | Monthly deadline calendar with a task tracker table |
| `meeting-prep-sheet.html` | Prepare for and document care-team meetings |
| `policy-draft-template.html` | Draft department policies section by section |

Each HTML file is standalone. Markdown versions (`.md`) are included for editing, copying, and accessibility.

## How to use

1. Open any `.html` file in your web browser (Chrome, Edge, Firefox, Safari).
2. Fill in the fields on screen, or print and complete by hand.
3. Print with your browser's Print command (Ctrl+P / Cmd+P). Pages are sized for US Letter and optimized for printing.
4. Each page has a "Print this form" button if you want a one-click print.

These files are local-first: nothing is uploaded, no account is required, and no data leaves your computer.

## Accessibility

- Large-print friendly: 16 px base text, larger headings, generous spacing, high contrast.
- Fillable input fields, checkboxes, and text areas work on screen and on paper.
- Designed for US Letter printing.
